# Production native world collector ownership

`native-world-scene.ts` and `WorldCollision.collectFaces` connect the independently
verified query kernels to production finite body/wheel collection. The static
spatial hash remains the unrestricted ray broad phase and the explicit legacy
collector when no native scene is supplied. Production source scenes do not fall
back to hash/render traversal when a native provider is missing.

## Source and portable resource policy

Installed HW SHA256 is `698c2b11865578b6ea2a77324fbc1840080841a8ae4041e9ca14ca5ff027bd6c`,
PE32/i386, base `0x400000`, entry `0x577eb0`. Existing subsystem evidence supplies
verified addresses and captures. rec2 is a symbol/structure map; implementation
is independent. Original files were read only.

The mutable native ACTs borrow exact parsed ACT/DAT/MAT identities and an ACT to
Three object crosswalk. Immutable authored ACT/DAT records are unchanged.
Admitted runtime MAT records intentionally receive native SmoothificatePowerups
coefficient/flag mutations; renderer wrappers receive the corresponding update.
The shared
host resource arena supplies real live MAT byte addresses for the recovered
unsigned comparator/unstable CRT permutation. This is the declared browser
allocator, not a Windows process heap capture. A particular original process's
multi-MAT finite prefix is neither specified by MAT files nor claimed here.
Completed DAT/ACT registry lookup absence is an actual NULL binding, rather
than an unresolved query provider. Installed MATERIAL_INDEX522a9b and
ACT_MATERIAL52316e store BrMaterialFind's return directly. Desert's literal
`!/75WATER` is admitted, but native slash-pattern termination means the same
lookup pattern does not match that literal identifier. The raw binding stays
NULL; actor material inheritance supplies the effective query material.

Initial layout is retained before mutation. Column extraction installs wrappers,
processes the selected ground MODEL, preserves remaining/migrated face ownership,
prepares generated groups after attachment, computes UV reserve without changing
counts, then prepares them again. Query-visible resources have matching prepared
revision. Pedestrian enrollment is a separate deferred owner: the production
outlet retains original face coverage rather than spawning again during this pass.

FindNonCars applies source local MODEL/name matches, raw-ID registration,
normalization, powerup smoothification/local pretranslation/CUSTOM flags and
shared changing-powerup MODEL copies, then compacts noncars in ascending raw ID.
The original actor-bound resources remain independent of MODEL bounds. Powerup
custom render callback names are retained in ACT metadata; rendering/time ownership
remains with the existing powerup renderer.

Startup REG/MATERIAL and REG/MODELS registration precedes race resources, following
LoadInRegistees/LoadInRegisteeDir. Installed DRLoadMaterials `48f020..76` clears
LIGHT and directly registers common MATs; DRLoadModels `48f080..dd` overwrites MODEL
flags with UPDATEABLE. DAT material-index bindings are captured at their original
load episode, including NULL, and reused when a common MODEL is admitted lazily
into the current query owner. Later race registrations cannot change those stored
pointers. The whole-installation read-only audit found the actual `&68`, `&69` and
`&70POWERUP1.ACT` resources in REG/MODELS. Junknet lacks a local `&70` MODEL; its
changing-powerup fallback therefore exercises the genuine startup registry.

Changing-powerup duplicate MODELs have independent current XYZ/UV/face tables and
retain actual source MAT references. Installed globals `69f170/174/178` persist
across race loads; the host cache is keyed by the actual Assets material-arena
lifetime. The first initialization prepares all three copies, and later scenes
admit those same copied identities. Referenced MATs acquire an explicit persistent
lease before race release, preserving their live arena addresses, render wrappers
and texture dependencies while their race-name registrations can be removed.
This models owned host-resource lifetime, without claiming captured Windows heap
addresses or reproducing an unavailable process allocation prefix.

## Collector and mutation ownership

FindFacesInBox visits expanded columns X outer/Z inner, then the actual additional
root. ActorBoxPick emits each MODEL before children and keeps callbacks alive at
capacity zero. Pull and stop callbacks execute interleaved with that traversal,
not by post-processing a completed face list. NONE-style actors prune subtrees.
ModelPickBox consumes the current prepared group/face order, source finite gates,
strict clipping and cached Float32 records. Surface records retain packed normals,
plane constants, current native indices and immutable DAT provenance separately.

Retaining/render-reparenting an ACT does not rewrite native parent links. Its live
local query matrix is reconstructed from the Three world pose relative to its
native parent world pose, including generated wrapper transforms. Moving-world
rows are captured before their model's stop notification alters subsequent state.

Current geometry changes are synchronized before collection/rebuild. Replacement
uses actual loaded DAT identity; private smash/crush geometry rebuilds current
raw XYZ/UV/flag tables, retaining original face provenance and separate remaining/
migrated ownership. Actual raw MAT crosswalks are used for runtime preparation.
Changed tables invalidate prepared revisions; immutable DAT and other ACT instances
keep their resources. Passthrough faces still consume finite capacity and retain
collision-mode metadata for later eligibility filtering.
Render geometry retains copied DAT metadata, so replacement identification
verifies canonical XYZ and authored face indices/material slots against the
exact registry DAT rather than comparing array references. Replacement render
face mappings remain separate from the initial track snapshot. Admitted
remaining/migrated face ownership survives later compaction and restoration;
current raw XYZ retains the original native pivot subtraction convention.

## Additional installed owner-phase audit

The current installed reader maps target WORD `spec+0x2ac` to the first authored
variable-change index. At `4f026d`, EBP becomes spec+2d0. `4f04d3` stores count at
EBP-28 (2a8), `4f04dc` addresses the first pair at EBP-26 (2aa), and `4f04fc` writes
the first input integer at pair+2 (2ac); `4f0500` writes the second at pair+0.
SetSmashableModel zero-extends that WORD at `4f5bea`; it is not a reserved field.
Target registration appends metadata and does not increment mission variables.

Installed PullActorFromWorld is `41ff20..35`, not rec2's annotated41ff00. It gates
on doing-physics748798 or sensible-place677c3c and calls DoPull41ff40. Existing
non-NULL ACT type_data returns NULL (`41ff49..59`), so repeated callbacks do not
prune an already registered ACT. Source type mapping/slot selection precedes
successful registration. Missing/exhausted slots overwrite identifier byte1 with
`x` and return NULL. Success sets driver4/ec1, stores type_data, clears velocity
and reparents through remove/add (`42006a..42007a`) to **gNon_track_actor7609d8**.
That container is outside FindFacesInBox's columns/additional root. Production
collector topology performs this detach/prepend when its physical host reports
success. Native dedicated/40-extra physical slot lifecycle remains the physical
noncar owner's responsibility; the collector does not synthesize slot history.

Drivable owners are a separate wheel phase and never consume the300-face ring.
MechanicsStep `4158b0..4158ed` scans PHIL748790 via object+220, snapshots the first50
owners with drivable byte+4d4 into79c180/count79c248. The wheel loop

only this snapshot and the current authored hull planes, visiting each shape

The camera's existing head-shape clipping kernel supplies the finite boundary

The runtime finite clipping needs no render-triangle bounds gate. It does not

## Validation

Focused production tests cover interleaved MODEL/stop/child-pull order, callbacks
at zero capacity and disabled emission, NONE pruning, successful pull removal,
render-reparent transform identity, live geometry/prepared revision invalidation,
and immutable DAT preservation. The separate wheel phase tests51-owner cap,
PHIL reorder, equal-hit owner ties, successor shapes, start-inside rejection and
an uncached static face that previously masked a valid drivable hit. Replacement
tests cover copied source metadata, nonzero pivot and two-to-one-to-two face
restoration. Both original Newcity datasets run actual
212-column preparation,26 generated MODELs/126 migrated faces, source canopy
normalization and a full300-row production prefix. Original tests skip cleanly
without the installation. Runtime Chromium validation is owned by the integration
root and reported separately.
Both Desert datasets also verify the explicit missing-lookup NULL contract. A real
common-load/Newcity/Junknet/release/Advanced-Junknet sequence verifies lazy common
MODEL admission, startup DAT material bindings, independent copied MODEL lifetime
and unchanged leased MAT addresses after race release.
The read-only mounted-installation audit ran one shared Assets session with real
common registration, the normal initial Newcity load, then all122 unique Stock
and Advanced race ACT stems. All123 preparation/release episodes passed with
actual smash tables and deliberate nonmission target metadata. This broader
provider/layout/lifetime audit does not replace per-mission gameplay validation.
