# Offene Arbeiten

## Executive Summary

Diese Liste sammelt die derzeit gefundenen Lücken, vereinfachten Umsetzungen und offenen Prüfungen. Sie basiert auf dem Code und den Kompatibilitätsnotizen nach Commit `6bba618`, Stand 2026-10-08. Gewöhnliche Fahrzeugphysik, lokales Crush, Komponentenbeschädigung, abtrennbare Teile und Reparatur sind integriert. Wasser, Öl und weitere Welt-/Powerup-Pfade haben Quellcodeabgleich und Headless-Abdeckung; die aktuelle Welt- und Minenintegration wartet noch auf Browserprüfung.

Die Prioritäten sind erste Vorschläge und können direkt in der Spalte **Prio** geändert werden. Die IDs bleiben dabei stabil. Innerhalb einer Priorität gibt es noch keine feste Reihenfolge.

| Prio | Bedeutung                                                            |
| ---- | -------------------------------------------------------------------- |
| 1    | Hoher Einfluss auf Fahr-, Crash- und Zerstörungsspielgefühl          |
| 2    | Wichtige Spielmechanik oder deutlich vereinfachtes Originalverhalten |
| 3    | Weitere Kompatibilität, Inhalte und größere Spielsysteme             |
| 4    | Qualitätssicherung, Robustheit, Wartbarkeit und Komfort              |
| 5    | Darstellung und UI mit geringerem Einfluss auf das Spielgefühl       |

**Status:** `Fehlt` = kein entsprechender Laufzeitpfad; `Teilweise` = vorhanden, aber eingeschränkt oder vereinfacht; `Prüfen` = konkrete offene Validierung, kein behaupteter neuer Bug; `Datenproblem` = auffällige Originaldaten, deren Behandlung noch zu klären ist.
