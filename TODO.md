# Outstanding work

## Executive Summary

This list records the gaps, simplified implementations and outstanding checks found so far. As of 2026-10-08, PHY-09 (interlocked cars) and AI-05 (opponents starting embedded in the ground) are fixed within the described scope and verified with numerical tests and original tracks in Chromium. DUNE BUGGERED was tested with the green Eagle, Buggy and Bigdump; NEW CITY serves as a control track. The renewed scale audit found no global vehicle scaling error, but did establish a camera discrepancy (REN-05). This list does not claim full C2 parity.

The priorities are initial suggestions and can be edited directly in the **Priority** column. IDs remain stable. There is no fixed ordering within a priority yet.

| Priority | Meaning                                                                    |
| -------- | -------------------------------------------------------------------------- |
| 1        | High impact on driving, crashes and destruction                            |
| 2        | Important gameplay mechanics or substantially simplified original behavior |
| 3        | Further compatibility, content and major game systems                      |
| 4        | Quality assurance, robustness, maintainability and convenience             |
| 5        | Presentation and UI with less impact on gameplay feel                      |

**Status:** `Done` = the described scope is implemented and verified; `Missing` = no corresponding runtime path; `Partial` = present, but limited or simplified; `Needs validation` = a specific outstanding check, not a claim of a new bug; `Reported` = a user-observed bug not yet reproduced or explained here; `Data issue` = unusual original data whose handling still needs to be established.
